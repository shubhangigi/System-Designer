# SYSTEM DESIGNER — AI-Powered Architecture & System Design Workspace

**System Designer** is an AI-powered system architecture design workspace that helps beginners and developers describe a software idea in plain English, retrieve architectural knowledge via RAG, generate production-ready software architectures using local open-weight or cloud LLMs, validate design choices, track version history, export project scaffolds, and detect architecture drift.

---

## 🌟 Key Features

1. **Free & Local-First AI Support**: Native integration with **Ollama** (e.g., `qwen2.5-coder:7b`, `llama3.2:3b`, `mistral`) running locally on modest hardware with zero mandatory paid API dependency.
2. **RAG Architecture Knowledge Pipeline**: Contextual retrieval from an indexed knowledge base covering monolithic vs microservices, PostgreSQL, Redis, auth, API security, caching, load balancing, payment systems, and WebSockets.
3. **Real Authentication & Project Isolation**: Password hashing (`bcrypt`), JWT session tokens in HTTP-only cookies, and PostgreSQL multi-tenant project ownership.
4. **5-Step Onboarding Wizard**: Guided project creation starting empty with optional domain templates (E-commerce, SaaS, Banking, Social, Healthcare, Collaboration).
5. **Interactive Architecture Canvas**: React Flow interactive canvas with color-coded component nodes, edge protocols, and an Inspector Panel providing beginner-friendly explanations (*What is this? Why is it needed? Why was it chosen? What if I remove it?*).
6. **Architecture Validation & Health Score**: Automated rule validator checking for security vulnerabilities, single points of failure, missing rate limits, or coupling.
7. **Scaffold Generator & ZIP Export**: Generates architecture-aware directory structure and starter code.
8. **Architecture Drift Detection**: Compares intended architecture against actual codebase to catch divergence.
9. **Technical Honesty**: Explicitly displays whether an architecture was generated by **Real AI (Ollama/OpenAI)** or **Fallback Logic**.

## 🚀 Quick Start (Local & Free)

### 1. Install Dependencies & Build

```bash
npm install
npm run build -w shared
npm run build -w backend
```

### 2. Configure Environment

Copy `.env.example` to `.env`:

```env
PORT=4100
NODE_ENV=development
GENERATION_MODE=ai

# Database
DATABASE_URL=postgresql://archspace:archspace@localhost:5433/archspace

# Authentication
JWT_SECRET=super-secret-dev-jwt-key-minimum-32-chars-long!
BCRYPT_ROUNDS=12

# Local Open-Weight AI (Ollama - Free & Local)
AI_PROVIDER=ollama
AI_BASE_URL=http://localhost:11434/v1
AI_MODEL=qwen2.5-coder:7b
AI_TIMEOUT_MS=120000
```

### 3. Start Local AI Model (Ollama)

```bash
# Install Ollama from https://ollama.com
ollama pull qwen2.5-coder:7b
ollama serve
```

### 4. Run Development Servers

```bash
npm run dev
```

- **Frontend UI**: http://localhost:5173
- **Backend API**: http://localhost:4100

## 📂 Repository Structure

- `shared/`: TypeScript canonical models, Zod schemas, validators, utilities.
- `backend/`: Express server, authentication middleware, AuthService, ProjectRepository, RAG retriever, provider factory, orchestrator.
- `frontend/`: React + Vite SPA, React Router DOM, Zustand stores, React Flow canvas, design system CSS, auth pages, wizard, 8-tab workspace.
- `database/`: Database schema and idempotent migrations (`001_initial_schema.sql`, `002_users_auth.sql`).
- `knowledge/`: Architecture knowledge base markdown files (architecture, databases, security, scalability, patterns).
- `tests/`: Vitest test suite for unit and integration testing.
